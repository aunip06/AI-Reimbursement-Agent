1. Extract this ZIP into the AI-Reimbursement-Agent project root.
   Allow folders such as models, workflow, tools, scripts, and pages to merge.

2. Activate .venv.

3. Apply the safe receipt schema patch:
   python -m scripts.patch_receipt_remark

4. Compile:
   python -m py_compile models\pdf_intake.py workflow\pdf_intake_workflow.py tools\pdf_intake_report_tool.py scripts\run_pdf_intake.py scripts\patch_receipt_remark.py pages\2_Document_Intake.py models\receipt.py prompts\receipt_prompt.py tools\cache_tool.py

5. Test the backend with an existing PDF:
   python -m scripts.run_pdf_intake --input "input\asha_kulkarni_may_2026.pdf"

6. Start Streamlit:
   python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501

7. Open the Document Intake page from the Streamlit sidebar.
